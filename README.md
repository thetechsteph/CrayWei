# Cray Wei

Immersive storytelling site: a freshwater journey from the crayfish to the table to the shop. React + Vite + React Three Fiber + GSAP.

```bash
npm install
npm run dev
```

Edit content in `src/data/` (`products.js`, `brand.js`, `dishes.js`). Dish photography lives in `src/assets/food/`.
Test the render tiers with `?mode=full|lite|still|static`.
